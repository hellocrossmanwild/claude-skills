# Claude skills

Free skills for building real apps with Claude, without the terminal.

## Project starter

Checks every tool you've connected to Claude actually works, interviews you about your app idea, then writes **CLAUDE.md**: your project's rules file (your stack, keys only ever in environment variables, every change on a branch, plain English first, and ask before deleting anything).

**Install**
1. Download [project-starter.zip](https://github.com/hellocrossmanwild/claude-skills/releases/latest/download/project-starter.zip). Don't unzip it.
2. In Claude, open **Customize → Skills**, and upload the zip. Make sure it's switched on.
3. Start a new chat and say: "Use the Project starter skill."
